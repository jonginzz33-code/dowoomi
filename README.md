# 업무 도우미 (dowoomi)

업무를 대신 처리해 주는 도우미 앱 — 기본 틀 v0.1.0

## 이번 버전에 들어간 것
- 앱 실행 시 권한 점검 팝업 (무엇이 되어 있고 무엇이 안 되어 있는지 표시)
- 권한 설정 화면: 다른 앱 위에 표시 / 알림 / 배터리 최적화 제외 / 개발자 옵션
- 메인 화면 메뉴 틀: 스크립트 목록, 읽기 영역 지정, 터치 설정, 셸 연결, 권한 설정, 실행

## 다음 단계
- 셸 연결 (무선 디버깅 페어링 → 셸 서비스 실행)
- 터치 주입 / 화면 캡처
- 스크립트 추가·수정·삭제
- 맨 위 상태 창 (오버레이)

## 빌드
GitHub에 올리면 Actions가 자동으로 APK를 빌드합니다.
Actions 탭 → 최신 실행 → Artifacts → Dowoomi-apk
